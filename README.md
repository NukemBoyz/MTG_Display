# MTG Display

A LAN scoreboard for tabletop card games. Run it on the PC attached to your TV,
and every player scans a QR code to get a life counter on their own phone.
Up to 20 matches, five on screen at a time.

Supports both **Magic** (20 life) and **Yu-Gi-Oh** (8000 life), switchable
mid-session from the operator window — the whole board, including the
backdrop, follows the mode.

Nothing is installed. No admin rights, no registry changes, no PATH changes.

---

## Download and run

1. Grab the latest `MTG_Display.zip` from the
   [Releases page](../../releases/latest).
2. Unzip it anywhere — Desktop or Documents is fine.
3. Double-click `MTG_Display.exe`.

A console window opens showing the address, and the board opens in your browser:

```
Open the board on this PC:      http://192.168.1.50:8080/
QR codes will point phones at:  192.168.1.50
```

Leave the console window open — closing it stops the server. Phones must be on
the **same Wi-Fi** as the PC.

On first run Windows will ask whether to allow it through the firewall. Say yes,
or phones will not be able to reach the board. If you miss that prompt, run
`ALLOW_FIREWALL.bat` as administrator.

## Using it

**The board** shows five matches at a time, scaling to fill the screen from
1080p up to 4K. Each player gets a QR code linking to their own phone counter.

**The operator window** (the `Operator` button, top right) is the control panel:

| Control | What it does |
| --- | --- |
| Page / Hide This Page | Move between pages, or clear the five matches on screen |
| Show All Matches | Bring every match back |
| Auto Cycle + 15/30/60s | Rotate through pages automatically |
| Magic (20) / Yu-Gi-Oh (8000) | Switch life-point system for all matches |
| Reset Life | Reset the current page back to starting life |
| All Matches | Tick to show, untick to hide — hidden matches vanish and the rest close ranks |
| Reset Everything | Clear all names, titles and life totals |

As matches finish, untick them. Remaining matches consolidate so the board never
shows empty slots.

**Match state is saved automatically** to
`%LOCALAPPDATA%\MTG_Display\state.json`. Delete that file to wipe everything.

## Options

Run from a terminal, or edit `MTG_OPTIONS` in `2_START_MTG.bat`:

```
--ip 192.168.1.50    force the address used in QR codes
--port 8090          use a different port
--no-browser         do not auto-open the board
```

The server ranks the PC's network adapters and prefers real LAN addresses, so
VPNs (Tailscale, WireGuard) and virtual adapters (Hyper-V, Docker, VirtualBox)
do not hijack the QR codes. Use `--ip` if it still picks wrong.

## Running from source

The `.exe` is just this Python program frozen with PyInstaller. To run it
directly instead:

1. Double-click `1_SETUP.bat` — downloads Python's official embeddable package
   into `python/`. Needs internet, takes about a minute, done once.
2. Double-click `2_START_MTG.bat`.

Only the standard library is used, so any Python 3.11+ works:

```bash
python server.py
```

### Building the .exe

```bash
pip install pyinstaller
pyinstaller MTG_Display.spec
```

Output lands in `dist/MTG_Display.exe`. It is fully self-contained — the HTML,
CSS, JavaScript and backgrounds are all bundled inside.

## Troubleshooting

**Phones cannot connect, board works on the PC**
Same Wi-Fi? Guest networks and cellular data are the usual culprits. Otherwise
it is the firewall — run `ALLOW_FIREWALL.bat` as administrator.

**QR codes are blank squares**
They are generated by `api.qrserver.com`, so they need internet. The typed link
under each code still works without it.

**"Port 8080 is already in use"**
Use `--port 8090`. On Windows, Hyper-V and WSL sometimes reserve port ranges —
check with `netsh interface ipv4 show excludedportrange protocol=tcp`.

**SmartScreen warns about the .exe**
It is unsigned. Click "More info" then "Run anyway", or run from source instead.
